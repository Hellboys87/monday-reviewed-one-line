A one-line review of Monday, written like a product review: one star, 47 unread emails, a 9 a.m. meeting that should have been email #48, no refund — and it auto-renews weekly. The program writes that single line (under 200 characters, nothing else) to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
